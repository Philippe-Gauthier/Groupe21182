
# PRATIQUE D'EXAMEN
- Correction automatique
## RÔLE
- Permettre à l'enseignant de pouvoir corriger plusieurs examens en important un fichier .txt externe contenant les réponses de l'étudiant.e et voir automatiquement sa note.
---
# COMMENT ÇA FONCTIONNE
## Partie 1
### Entrée

- Les réponses de l'étudiant.e dans examen.py

### Sortie
- Un fichier .txt qui contient les réponses entrées.
  
## Partie 2
### Entrée
- Le même fichier .txt qui contient les réponses entrées.
  
### Sortie
- La note. (Nombre de bonnes réponses).
